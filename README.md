# kv-cache-eviction

Code and per-item records for **"Similar Accuracy, Opposite Failure: A Failure-Mode Decomposition of KV-Cache Eviction in Multilingual Long-Context Retrieval."**

Two scripts:

- **`modal_kv_audit_v4.py`** — the sweep. Generates ONERULER data, runs 3 eviction policies × 2 budgets × 2 protocols × 7 languages on 2 models at 32K tokens, and writes one record per generation. Needs a GPU; runs on [Modal](https://modal.com).
- **`post_run_calc.py`** — all analysis. Recomputes every number in the paper from those records. CPU only, ~2 minutes, no Modal account needed.

The records are committed, so **you can reproduce every table and figure without touching a GPU.** Start at [Quickstart](#quickstart).

📄 Paper: preprint coming soon (link TBD).

---

## What the experiment measures

Eviction is normally reported as a delta in averaged benchmark accuracy. That statistic scores a wrong answer and a withheld answer identically, so it can't distinguish a policy that goes silent from one that emits confident garbage. Using ONERULER's present-needle (`niah_single`) and absent-needle (`niah_none`) tasks, this sweep splits retrieval into a *detection* decision (answer or abstain) and *identification precision* given an answer.

Llama-3.1-8B, 25% KV budget, query-agnostic protocol:

| Policy | Official acc. | Answer rate | **Precision when answering** |
|---|---|---|---|
| full cache | 0.91 | 0.93 | 0.98 |
| KNorm | 0.21 | 0.62 | **0.34** |
| SnapKV | 0.35 | 0.43 | 0.81 |
| StreamingLLM | 0.25 | 0.25 | **0.99** |

A leaderboard calls KNorm and StreamingLLM roughly tied. One is wrong on two-thirds of the answers it gives; the other is wrong on one-hundredth. The wrong values are mostly *corrupted copies* of real context values (263 of 272 near-misses under KNorm-25% are truncations of the true needle's digits), not inventions. Rankings also move with query visibility — SnapKV gains up to +0.75 accuracy when the policy can see the question. Two ONERULER defects surfaced along the way: degenerate Korean haystacks (341 unique sentences out of 1,589; one repeated 171×) and an absent-needle scorer that credits any response containing the none-word, including ones that list all four distractor values first.

Details, CIs, and caveats are in the paper. Everything below is about running the code.

## Quickstart

Reproduce the analysis from the committed records:

```bash
pip install numpy pandas pyarrow
python post_run_calc.py                      # defaults: --v4-dir ./results --out ./post_run
```

~2 minutes. Writes ~20 CSVs plus `post_run/post_run_report.md` (prose summary with the numbers filled in) and `post_run/post_run_v11/v11_numeric_diff.md` (every headline number, recomputed).

Sanity-check the machinery on fabricated data with known answers:

```bash
python post_run_calc.py --selftest
```

## Layout

```
modal_kv_audit_v4.py     # sweep (GPU, Modal)
post_run_calc.py         # analysis (CPU, local)
results/
  results.parquet        # 29,400 per-item records (29,442 rows incl. 42 tagged toy rows)
  raw/*.jsonl            # the same records, one file per cell config hash
  cells/*.jsonl          # per-batch cell summaries (informational only)
  cell_table.csv         # per-cell accuracy
  gap_table.csv          # per-language gaps, bootstrap CIs, BH-corrected q
  arm_contrast.csv       # query-agnostic vs. query-aware per (lang, press, budget)
  failure_modes.csv  failure_mode_deltas.csv  scorer_sensitivity.csv
  diagnosis_knorm_*.csv  # per-(layer, head) key-norm keep rates by span
  depth_balance.csv  streaming_by_depth.csv  fertility_*.csv  summary_stats.json
post_run/                # analysis output (regenerated by post_run_calc.py)
figures/                 # sweep figures
logs/                    # per-stage run logs + frozen environment dumps
```

Analysis reads `results/results.parquet` if present, else `results/raw/*.jsonl`; the two are equivalent.

## `post_run_calc.py`

```bash
python post_run_calc.py [--v4-dir ./results] [--out ./post_run] [--only all|v2|v11] ...
```

| Flag | Default | Purpose |
|---|---|---|
| `--v4-dir` | `./results` | Directory holding `results.parquet` or `raw/` |
| `--out` | `./post_run` | Output directory |
| `--v4-script` | `./modal_kv_audit_v4.py` | Imported for its exact scorers; cross-checked against the built-in fallback on real rows |
| `--only` | `all` | `v2` = value origin + protocol contrast; `v11` = value origin, scorer split, Figure 2 composition, numeric diff |
| `--data-dir` | — | Downloaded ONERULER data; makes redundancy + value-origin checks exact rather than language-approximate |
| `--remote-text` | — | Output of the optional `--stage text-stats` Modal job (same effect without the 180MB download) |
| `--boot` | `2000` | Bootstrap iterations |
| `--expect-n` | `29400` | Abort unless this many real rows survive the toy filter and dedup; `0` disables |
| `--selftest` | — | Run on fabricated data with known answers and exit |

**Key outputs**

| File | Contents |
|---|---|
| `detection.csv` | Answer rates on both tasks, d′, c per condition |
| `post_run_v11/figure2_composition.csv` | Present-trial outcome split: correct / near-copy / other wrong / abstain |
| `post_run_v11/value_origin_trials.csv` | Value-origin taxonomy (exact / near-copy / novel) with Wilson CIs; `_cands` = candidate level, `_chance` = Monte-Carlo false-positive rate of the near-copy rule |
| `protocol_contrast.csv`, `protocol_by_lang.csv` | Query-agnostic vs. query-aware, paired item bootstrap |
| `dispersion.csv`, `amplification.csv` | Cross-language overdispersion φ and compressed/baseline ratio with paired CIs |
| `redundancy.csv`, `redundancy_link.csv` | Tokenizer-free haystack redundancy per language + link to content-press retention |
| `post_run_v11/scorers_strict_none.csv` | Official vs. strict absent-needle scoring, per cell |
| `positional_law.csv` | StreamingLLM accuracy vs. `baseline × kept` (the budget-accounting control) |
| `arm_invariance.csv` | `press=none` qa-vs-joint per-item agreement (the determinism control) |
| `ordering.csv`, `fertility.csv`, `depth.csv`, `errors.csv`, `power.csv` | Language ordering with exact permutation p + LOO, fertility correlations, depth balance, failure modes, power |

For text-dependent analyses without downloading the data:

```bash
modal run post_run_calc.py --stage text-stats
modal volume get kv-audit-vol postrun ./post_run_remote
python post_run_calc.py --remote-text ./post_run_remote
```

## `modal_kv_audit_v4.py`

Single-file Modal app. Pins its own image (`torch==2.13.0`, `transformers==5.2.0`, `kvpress==0.5.4`, `datasets==5.0.0`), runs on one L40S, and needs a Modal secret named `huggingface-secret`. State lives in the volume `kv-audit-vol`.

```bash
pip install modal && modal setup
```

### Stages

```bash
modal run modal_kv_audit_v4.py --stage <stage> [--model ...] [--arm ...] [--task ...] [--n 100]
```

| Stage | What it does |
|---|---|
| `smoke` | Per-model GPU sanity: press semantics, positional invariants, chunked==stepwise under compression; logs the resolved HF revision |
| `selftest` | Scorer unit tests + end-to-end toy run across both arms and both tasks |
| `prepare-data` | Clone the ONERULER repo into the volume (idempotent) |
| `gen-data` | Generate `niah_single` / `niah_none` contexts at the target length |
| `split-audit` | Print each language's derived context/question marker and an example question — **eyeball this before sweeping** |
| `baselines` | Uncompressed cells only |
| `sweep` | All cells for one (model, arm, task): baseline + 3 presses × 2 budgets × 7 languages |
| `aggregate` | `raw/*.jsonl` → `results.parquet` + `cell_table.csv` |
| `analyze` | Gap tables with paired bootstrap + BH correction, depth balance, arm contrast; figs 1, 1b, 2, 3, 5, 6 |
| `failure-modes` | `failure_modes.csv`, `failure_mode_deltas.csv`, `scorer_sensitivity.csv`; fig 4 |
| `diagnose` | Replays KNorm's keep-lowest-norm selection offline from k_proj hooks; keep rates for needle-value / needle-window / question / haystack spans; fig 7 |
| `fertility` | Tokenizer fertility per language, measured on FLORES and on the eval texts |
| `status` | Which cells are done for a given (model, arm, task) |
| `inspect` | Print predictions for one cell (`--only-wrong` to filter) |
| `wipe-results` | Clear results; keeps generated data, the ONERULER clone, and the HF cache. Needs `--confirm` |

### Flags

| Flag | Values | Default |
|---|---|---|
| `--model` | `llama31-8b`, `qwen25-7b-1m` | `llama31-8b` |
| `--arm` | `qa` (query-agnostic, primary), `joint` (query-aware) | `qa` |
| `--task` | `niah_single`, `niah_none` | `niah_single` |
| `--langs` | comma-separated | `en,pl,zh,ja,ko,vi,sw` |
| `--n` | items per language×task | `100` |
| `--ctx-len` | context length | `32768` |
| `--seed` | | `42` |
| `--press`, `--kept` | for `diagnose` / `inspect` | `knorm`, `0.5` |

Models are pinned by revision in the `MODELS` registry; presses, budgets, and the language set are frozen constants near the top of the file.

### Full campaign

```bash
modal run modal_kv_audit_v4.py --stage smoke --model llama31-8b
modal run modal_kv_audit_v4.py --stage smoke --model qwen25-7b-1m
modal run modal_kv_audit_v4.py --stage selftest
modal run modal_kv_audit_v4.py --stage prepare-data

modal run --detach modal_kv_audit_v4.py --stage gen-data --task niah_single --n 100
modal run --detach modal_kv_audit_v4.py --stage gen-data --task niah_none   --n 100
modal run modal_kv_audit_v4.py --stage split-audit --task niah_single
modal run modal_kv_audit_v4.py --stage split-audit --task niah_none

for m in llama31-8b qwen25-7b-1m; do
  modal run --detach modal_kv_audit_v4.py --stage sweep --model $m --arm qa    --task niah_single --n 100
  modal run --detach modal_kv_audit_v4.py --stage sweep --model $m --arm joint --task niah_single --n 100
  modal run --detach modal_kv_audit_v4.py --stage sweep --model $m --arm qa    --task niah_none   --n 100
done

modal run modal_kv_audit_v4.py --stage aggregate
modal run modal_kv_audit_v4.py --stage analyze
modal run modal_kv_audit_v4.py --stage failure-modes

modal volume get kv-audit-vol results ./results
modal volume get kv-audit-vol figures ./figures
```

29,400 generations total. Then run `post_run_calc.py` over the downloaded `results/`.

## Record schema

One JSON object per generation, in `results/raw/*.jsonl` and `results/results.parquet`:

```json
{
  "model": "llama31-8b", "arm": "qa", "lang": "pl", "ctx_len": 32768,
  "press": "snapkv", "kept": 0.5, "task": "niah_single", "seed": 42, "toy": false,
  "config_hash": "0135dc581385f466", "sample_id": 0, "depth": 0.0413,
  "input_length": 32861, "context_tokens": 32735, "question_tokens": 131,
  "compressed_len": 16367,
  "correct": false, "pred": "<odpowiedź> 286782. </odpowiedź>", "gold": ["2867825"],
  "model_id": "meta-llama/Llama-3.1-8B-Instruct", "wall_s": 5.3, "ts": 1785145174
}
```

That row is the paper's truncation signature in miniature: the model emits the first six digits of the 7-digit needle and stops.

Cells are fully crossed and the same 100 items are reused across conditions within each language×task, which is what makes the paired bootstrap valid (B=3000, resampled within language, indices shared across paired conditions).

## Notes and gotchas

- **Detection coding is scorer-independent.** A trial counts as *answered* iff the NFKC-normalized output contains a digit run of length ≥ 6. Official scoring enters only through correctness on answered present trials. This matters because the official absent-needle scorer is substring-based and credits responses that emit values alongside the none-word.
- **`toy: true` rows** are smoke-test artifacts that reuse real `sample_id`s. They must be filtered *before* dedup — `post_run_calc.py` does this and reports the count.
- **`--expect-n 29400`** is a guard, not a formality: it catches a partial `modal volume get` before it silently changes your numbers.
- **kvpress ratio semantics.** `compression_ratio` means *fraction removed*; `KVPRESS_RATIO_MEANS_REMOVED` encodes this and `smoke` verifies it empirically, so a library change fails loudly rather than inverting every budget.
- **Budgets in the `qa` arm are fractions of the context** — question tokens are always retained. In the `joint` arm the denominator is the whole prompt (a ~0.4% difference at 32K).
- **Run-to-run instability.** Two runs sharing identical token IDs flip correctness on 29/1,400 items (2.1%), concentrated in Qwen/Swahili — inference-stack nondeterminism that wasn't eliminated. Per-cell claims near that magnitude should be read accordingly.
- **Single seed (42), single context length (32K), eviction only.** Language selection was conditioned on baseline results (a 0.6 floor filter dropped hi, ru, ta), and the benchmark audits are post hoc. Nothing was preregistered.
